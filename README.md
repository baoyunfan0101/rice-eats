# Rice吃啥 (Rice Eats)

> 项目开发中 / Under development

Rice吃啥 是一个面向莱斯大学 (Rice University) 周边地区的美食指南和交互式餐厅地图，帮助大家发现休斯顿 Rice 附近值得一去的餐厅。

Rice Eats is a food guide and interactive restaurant map for the area surrounding Rice University in Houston.

## Status

This project is in an early stage. The repository currently contains only project documentation and conventions; the website has not been implemented yet. The initial version will be in Chinese.

## Planned Features

- List, grid, and map views of restaurants
- Restaurant detail pages with personal reviews, text, and photographs
- Responsive layouts for desktop and mobile browsers
- Static hosting through GitHub Pages
- AI-assisted content management using `AGENTS.md` and reusable agent skills

## Planned Technology Stack

- React
- TypeScript
- Vite
- Tailwind CSS
- Leaflet
- Markdown
